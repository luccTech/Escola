## Proposta (v1.0)

O **Escola++** é um sistema de gestão escolar em linha de comando (Python), pensado para apoiar o acompanhamento básico de alunos em ambiente educacional.

Na versão **1.0**, o foco é oferecer um núcleo funcional com:

- **Cadastro e manutenção de alunos** — listar, incluir, editar e excluir registros (nome, CPF, turma).
- **Notas e frequência** — visualizar boletim geral e lançar ou atualizar nota e percentual de frequência por aluno.
- **Alertas de risco** — identificar alunos com nota abaixo de 6 e/ou frequência abaixo de 75%, com painel de alertas críticos e contagem no menu principal.

Os dados ficam em memória durante a execução (`dados.py`), sem persistência em arquivo ou banco — adequado para protótipo e evolução futura do projeto.

**Requisito:** Python 3 instalado.

**Execução:**

```bash
python main.py
```
